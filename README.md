# BoardID Pinterest Finder 📌

> A simple tool to extract the numerical ID of Pinterest Boards.

[Access the online project](https://board-id-pinterest-finder.vercel.app/) | [View code on GitHub](https://github.com/pedromarcioap/boardId-pinterest-finder)

## 📝 About

The **BoardID Pinterest Finder** is a web utility that allows users to easily find the unique identifier (**Board ID**) of any public Pinterest board (folder). This ID is often required to configure widgets, plugins, or make calls to the Pinterest API, but it is not directly visible in the user interface.

## 🚀 Features

* **Quick Extraction:** Get the board ID by simply pasting the URL.
* **Clean Interface:** Design focused on usability without distractions.
* **No Login Required:** No authentication or Pinterest account access is needed.

## 🛠️ How to Use

1. Access the website: [https://board-id-pinterest-finder.vercel.app/](https://board-id-pinterest-finder.vercel.app/)
2. Go to Pinterest and copy the URL of the board you want (e.g., `https://br.pinterest.com/usuario/nome-da-pasta/`).
3. Paste the URL into the input field on the website.
4. Click the button to search/fetch.
5. Copy the generated **Board ID**.
