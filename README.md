# BoardID Pinterest Finder 📌

> Uma ferramenta simples para extrair o ID numérico de Boards do Pinterest.

[Acesse o projeto online](https://board-id-pinterest-finder.vercel.app/) | [Ver código no GitHub](https://github.com/pedromarcioap/boardId-pinterest-finder)

## 📝 Sobre

O **BoardID Pinterest Finder** é uma utilidade web que permite aos usuários encontrar facilmente o identificador único (Board ID) de qualquer pasta pública do Pinterest. Esse ID é frequentemente necessário para configurar widgets, plugins ou realizar chamadas à API do Pinterest, mas não fica visível diretamente na interface do usuário.

## 🚀 Funcionalidades

- **Extração Rápida:** Obtenha o ID do board colando apenas a URL.
- **Interface Limpa:** Design focado na usabilidade sem distrações.
- **Sem Login:** Não é necessário autenticação ou acesso à conta do Pinterest.

## 🛠️ Como Usar

1. Acesse o site: [https://board-id-pinterest-finder.vercel.app/](https://board-id-pinterest-finder.vercel.app/)
2. Vá até o Pinterest e copie a URL do board que deseja (ex: `https://br.pinterest.com/usuario/nome-da-pasta/`).
3. Cole a URL no campo de entrada do site.
4. Clique no botão para buscar.
5. Copie o **Board ID** gerado.
